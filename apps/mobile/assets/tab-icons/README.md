# Native tab icons

Android image sources use the existing Lucide icon set (house, compass, users,
circle-user-round and log-in), licensed under the included ISC license. iOS uses
SF Symbols. SVGs preserve the Lucide 24-unit source geometry; PNGs are transparent
24-pixel and 72-pixel exports for 1×/3× density. Keep the source and both exports
in sync when changing an icon. The native bar applies its theme tint.
