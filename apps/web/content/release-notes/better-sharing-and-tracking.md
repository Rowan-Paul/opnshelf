## Share a clearer preview

Public Web links now have richer sharing previews for media, Profiles, Lists, Reviews, search, and What’s new. Share a link to give people more context before they open it.

## See episode progress catch up

Episode progress refreshes after Shelf changes on both Web and Mobile, keeping the progress you see in step with your tracking.

## A tidier Mobile layout

Button labels stay on one line, and Up Next cards align within each row for a more consistent layout.

**Availability:** These improvements are included in the v1.7.9 release. Sharing previews are provided by Web. Mobile tracking and layout changes use an over-the-air update for compatible iOS and Android installations on app version 1.7.2. Let the update download, then close and reopen the app to load it.
