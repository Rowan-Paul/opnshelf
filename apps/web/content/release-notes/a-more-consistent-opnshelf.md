## A more familiar experience everywhere

Home, Social, Profiles, Calendar and detail pages have a more consistent look across Web and Mobile. Up Next on Mobile now uses episode images, and recent Movies on Profiles use wider artwork.

## More ways to explore and interact

Search, sort and filter Lists on Mobile, including Lists belonging to other people. On Web, you can like Reviews; on Mobile, you can manage Notes from more places.

## Easier feedback and smoother browsing

When sending feedback on Mobile, you can include a screenshot to help explain what you saw. Web pages load with less initial JavaScript and lighter hero images. This release also fixes a missing-rating display and improves navigation and editing across both clients.

**Availability:** These improvements arrive on Web with this release. Mobile changes require version 1.7.11, which is coming to the App Store and Google Play after the store release and review.
