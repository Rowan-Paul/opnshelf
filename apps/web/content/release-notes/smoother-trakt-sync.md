## Keep Trakt Sync moving

Trakt Sync catch-up does less work behind the scenes. Pages of items that need attention keep their navigation protected while loading, making it easier to review and resolve sync issues.

The retired one-time Trakt Import has been removed. Use Trakt Sync in Settings to manage transfers; existing Watches are retained.

## Move around more comfortably

On Mobile, Trakt confirmations use compact bottom sheets, section headings stay fully visible, and Back navigation from pickers works more reliably. Duo layouts also fit the screen more comfortably.

**Availability:** These improvements are included in the v1.7.8 release. Web receives changes through the production deployment. Mobile changes use an over-the-air update for compatible iOS and Android installations on app version 1.7.2. Let the update download, then close and reopen the app to load it.
