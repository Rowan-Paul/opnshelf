# Logos

- `opnshelf-mark.svg`: the standalone mark, transparent. Shelf in Slate Ink (`slate-900`), tile in Screen Amber (`accent-600`). For favicons, compact navigation, avatars. On dark grounds use the adaptive foreground or the app icon instead: the ink is fixed in the file.
- `opnshelf-lockup.svg`: the mark with the wordmark, for light grounds. The wordmark is live text in Timeless Sans Bold; shown as an image it falls back to a system face, so convert it to outlines before sending artwork out.
- `opnshelf-app-icon.svg`: the launcher and social treatment, Paper shelf on a full-bleed Slate Ink square. The operating system applies its own mask.
- `opnshelf-adaptive-foreground.svg`: Paper shelf with the amber tile on a transparent 1024 canvas, inset for Android adaptive icons and dark splash screens.
- `opnshelf-banner-1500x500.png`: social profile banner.
- `opnshelf-feature-1024x500.png`: Play Store feature graphic.

Keep clear space equal to the height of the amber tile. Do not recolor the tile, rotate the mark, or add gradients or shadows.
