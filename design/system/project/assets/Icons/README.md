# Icons

The five Mobile tab-bar icons: `home.svg`, `discover.svg`, `social.svg`, `profile.svg`, `login.svg`. They are Lucide glyphs on a 24px grid with a 2px black stroke and round caps, exported as files because the native tab bar needs images. The tab bar tints them; as plain images they are black.

Every other icon in the product comes from Lucide directly (`lucide-react`, `lucide-react-native`).
