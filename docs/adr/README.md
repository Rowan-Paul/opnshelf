# Architectural decision records

One file per decision. The filename is the stable reference: other documents
and commit messages link to it, so cite the filename where you can.

Numbering notes:

- Four numbers were once used twice (0002, 0005, 0015 and 0019). The less
  cited file of each pair was renumbered to 0027–0030; the table below is the
  authoritative mapping.
- Titles carry the number as `# ADR 00NN: Title`. Two older files (0014 and
  0021) use a different separator; the number column below is taken from the
  filename.
- Status is the ADR's own status line or section where it has one. Files
  without one are listed as "Accepted (implicit)": they describe a decision
  that was carried out and nothing supersedes them.
- New ADRs take the next free number after the highest in this table.
